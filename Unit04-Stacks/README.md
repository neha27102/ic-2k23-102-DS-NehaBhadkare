
# Stack Implementation in C++

This repository contains different implementations and applications of the Stack data structure using C++.

The programs demonstrate stack operations, expression conversion, and expression evaluation using both static arrays and linked lists.

## Programs Included

### 1. Static Stack Implementation
- Push an element
- Pop an element
- Peek / Top element
- Display stack elements
- Check Stack Overflow and Underflow

### 2. Dynamic Stack Implementation (Linked List)
- Push an element
- Pop an element
- Peek / Top element
- Display stack elements
- Dynamic memory allocation

### 3. Infix to Postfix Conversion
- Converts infix expressions into postfix expressions.
- Uses operator precedence and associativity.
- Uses stack operations for conversion.

### 4. Infix to Prefix Conversion
- Converts infix expressions into prefix expressions.
- Uses expression reversal and stack operations.
- Handles parentheses and operator precedence.

### 5. Expression Evaluation
- Evaluates postfix expressions using a stack.
- Supports arithmetic operators:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)
  - Exponentiation (^)

## Technologies Used

- **Language:** C++
- **Concepts:** Stack, Arrays, Linked Lists, Pointers, Functions
- **Header File:** iostream

## How to Run

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder in VS Code.

3. Compile the required C++ file:

   ```bash
   g++ filename.cpp -o output
   ```

4. Run the program:

   ```bash
   ./output
   ```

   On Windows:

   ```bash
   output.exe
   ```
