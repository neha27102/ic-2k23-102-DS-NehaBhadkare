
# Queue Implementation in C++

This repository contains different implementations and applications of the Queue data structure using C++.

The programs demonstrate Static Queue, Dynamic Queue, Circular Queue, Deque, and Priority Queue using arrays and heaps.

## Programs Included

### 1. Static Queue (Array)
- Enqueue
- Dequeue
- Peek / Front
- Display
- Overflow and Underflow handling

### 2. Dynamic Queue (Linked List)
- Enqueue
- Dequeue
- Peek / Front
- Display
- Dynamic memory allocation

### 3. Circular Queue (Array)
- Enqueue
- Dequeue
- Peek / Front
- Display
- Circular indexing using modulo operator

### 4. Deque (Double Ended Queue)
- Insert at Front
- Insert at Rear
- Delete from Front
- Delete from Rear
- Peek Front
- Peek Rear
- Display

### 5. Priority Queue (Array)
- Insert element with priority
- Delete highest-priority element
- Peek
- Display
- Priority-based element arrangement

### 6. Priority Queue (Heap)
- Max Heap implementation
- Insert element
- Delete / Extract Maximum
- Peek
- Heapify Up
- Heapify Down
- Display

## Technologies Used

- **Language:** C++
- **Concepts:** Arrays, Linked Lists, Pointers, Classes, Functions, Binary Heap
- **Header File:** iostream

## How to Run

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder in VS Code.

3. Compile the required C++ file:

   ```bash
   g++ filename.cpp -o output
   ```

4. Run the program:

   ```bash
   ./output
   ```

   On Windows:

   ```bash
   output.exe
   ```
