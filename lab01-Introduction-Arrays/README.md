Program 01: Array Operations

1. Problem Statement

Write a C++ program to perform basic operations on a one-dimensional array, such as insertion, deletion, traversal, searching, and updating elements.

2. Approach

- Declare an array and initialize its size.
- Accept elements from the user.
- Display the array elements using traversal.
- Perform insertion at a specified position.
- Perform deletion from a specified position.
- Search for a given element.
- Update an element at a specified position.
- Display the updated array.

3. Time and Space Complexity Analysis

Operation| Time Complexity
Traversal| O(n)
Insertion| O(n)
Deletion| O(n)
Searching| O(n)
Updating| O(1)

Space Complexity: O(n) for storing the array.

4. Sample Input/Output

Sample Input:

Enter array size: 5
Enter elements: 10 20 30 40 50

Sample Output:

Original Array: 10 20 30 40 50
Element 30 found at position 3
Updated Array: 10 20 35 40 50
