Program 03: Sparse Matrix

1. Problem Statement

Implement a sparse matrix representation to efficiently store a matrix containing mostly zero elements.

2. Approach

- Accept matrix dimensions.
- Input matrix elements.
- Identify non-zero elements.
- Store non-zero elements using an appropriate sparse matrix representation.
- Display the resulting representation.

3. Time and Space Complexity

For a matrix with m rows, n columns, and k non-zero elements:

- Time Complexity: O(m × n) for scanning the matrix.
- Space Complexity: O(k) for storing non-zero elements, excluding the input matrix.
